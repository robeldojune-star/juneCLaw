# Strategy Source Extracts

이 폴더는 사용자가 제공했거나 이전 작업에서 추출한 원본 전략 자료를 보관하는 위치입니다.

## 현재 파일

- `export.md`
- `export__1_.md`
- `export__2_.md`
- `export__3_.md`
- `export__5_.md`

## 운영 기준

- 이 폴더의 문서는 원문/추출물 성격이므로 직접 운영 기준으로 사용하지 않는다.
- 실제 의사결정 기준은 `docs/strategies/00_master_trading_plan.md`와 numbered report를 우선한다.
- 원문에서 새로 반영할 내용이 있으면 `docs/strategies/NN_topic_YYYY-MM-DD.md`로 요약 보고서를 만든 뒤 마스터 플랜에 핵심만 반영한다.
