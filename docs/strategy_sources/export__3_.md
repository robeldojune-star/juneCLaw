동적 시간 와핑 (Dynamic Time Warping{{1}}, DTW) 알고리즘을 이용한 패턴 매칭은 두 시계열 데이터 사이의 시간축상 비선형 신축을 허용하여 최적의 정렬 상태와 유사도를 계산하는 방식으로 이루어집니다. 이 과정은 단순한 지점 간 비교를 넘어 시계열의 형태적 유사성을 포착하는 데 특화되어 있습니다.데이터 전처리 및 거리 행렬 구축가격 데이터 정규화주가 패턴 매칭 시 서로 다
른 가격 수준을 가진 종목이나 기간을 비교하기 위해 정규화{{2}} 과정이 선행됩니다. 주로 평균을 0, 표준편차를 1로 만드는 Z-score 정규화나 0에서 1 사이로 값을 조정하는 Min-Max 정규화가 사용되며, 이는 절대적인 가격 수치가 아닌 상대적인 움직임
의 형태에 집중하기 위함입니다.거리 행렬 산출전처리가 완료된 두 시계열 \(X\)와 \(Y\)에 대해 모든 가능한 지점 쌍 간의 거리를 계산하여 거리 행렬을 생성합니다. 이때 개별 지점 간의 거리 측정에는 주로 유클리드 거리{{3}} (Euclidean distance)나 맨해튼 거리가 사용됩니다.누적 비용 행렬 및 최적 경로 탐색동적 계획법 기반 비용 계산단순 거리 행렬을 바탕으로 동적 계획법{{4}} (Dynamic Programming)을 적용하여 누적 비용 행렬을 산출합니다. 시작점 \(g(1,1)\)에서 시작하여 특정 지점까지 도달하는 최소 비용을 다
음
과 같은 재귀적인 방식으로 계산합니다.\[g(i, j) = d(i, j) + \min{g(i-1, j), g(i, j-1), g(i-1, j-1)}\]여기서 \(d(i, j)\)는 해당 지점의 즉각적인 거리를 의미합니다.와핑 경로의 제약 조건최적의 경로를 찾을 때는 현실적인 정렬을 위해 몇 가지 제약 조건{{5}}이 적용됩니다.경계 조건: 경로는 항상 행렬의 시작점 \((1,1)\)에서 시작해 끝점 \((N,M)\)에서 종료되어야 합니다.단조성: 시간의 흐름을 역행할 수 없으므로 경로의 인덱스는 감소하지 않고 계속 증가하거나 유지되어야 합니다.연속성: 경로의 단계는 인접한 지점으로만 이동해야 하며 시간축을 건너뛸 수 없습니다.패턴 매칭 및 거래 활용슬라이딩 윈도우 기반 탐색실제 시장 데이터에 적용할 때는 긴 데이터 스트림에서 슬라이딩 윈도우{{6}} 기법을 사용하여 참조 패턴과 가장 유사한 구간을 지속적으로 검색합니다. 짧은 패턴을 긴 시계열 내에서 찾는 이 방식은 실시간 수신 데이터에서 특정 형태의 추세를 감지하는 데 효과적입니다.매매 신호 생성 및 검증매칭된 패턴의 유사도(DTW 거리)가 특정 임
계치{{7}} 이하일 경우 이를 유효한 신호로 판단합니다. 과거 학습 기간 동안 해당 패턴 발생 후 가격이 상승한 빈도가 높다
