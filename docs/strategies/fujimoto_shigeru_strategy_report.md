- 거시경제 요인은 **선택적 보조 필터** 또는 **시장 레짐 필터**로 별도 고려 가능

## 3. 백테스트를 위한 신호 기반 기반 정립 부족 현황
### 현재 문제점
1. **신호 미정의**: 
   - `evaluate_fujimoto_126()` 함수는 `score_total`과 `position_stage`를 반환하지만, 
   - 실제 **매수/매도 신호 조건**이 코드에 없음
   - 예: `score_total >= 60 AND position_stage == 'STAGE3'` 를 신호로 볼지 여부 미정의
2. **청산 규칙 미구현**:
   - 진입 로직은 존재하지만, 청산 조건(손절/목표수익/시간청산) 없음
   - 현재 `simulate_fujimoto_126_trade()`에 간단한 청산 로직이 있지만, 전략 필터와 분리됨
3. **신호 품질 검증 부재**:
   - 신호 발생 빈도, 승률, 수익 팩터 등을 평가할 백테스트 파이프라인 미구축

### 증거: 현재 백테스트 준비도 게이트 상태
```bash
# 백테스트 준비도 게이트 실행 결과 (2026-05-30 기준)
docker compose -f /home/june/n8n/docker-compose.yml exec -T trading-runner \
  python scripts/run_daily_workflow_stage.py --stage backtest_opening_strategy_90d --pretty
```
→ `rows_used=43` (최소 300 필요), `total_variant_trades=0` (최소 5 필요)로 **차단** 
→ 근본 원인: ka10080 데이터 부족 (약 45 거래일 확보 중) + 신호 정의 미비로 거래 발생 안 함

## 4. 구현을 위한 구체적 계획

### 단계 1: 신호 및 청산 규칙 확정 (우선순위 높음)
| 항목 | 결정 사항 | 근거/참조 |
|------|-----------|-----------|
| **매수 신호** | `score_total >= 60 AND position_stage == 'STAGE3'` | 연구 노트의 "추세 확정 후 본 진입" 단계 대응 |
| **매수 진입가** | 당일 첫 신호 발생 시점의 종가 (또는 다음 시가) | 슬리피지 최소화를 위해 |
| **포지션 사이징** | 1:2:6 분할 (총 투자금의 1/9 → 2/9 → 6/9) | 연구 노트 명시 |
| **분할 진입 조건** | 1단계: 신호 발생<br>2단계: 1단계 진입 후 +0.5% 상승<br>3단계: 2단계 진입 후 추가 +1.0% 상승 | 추세 확증 필요성 반영 |
| **청산 규칙** | - 손절: 진입가 -2%<br>- 목표수익: 진입가 +3% (50% 청산 후 restante 트레일링 스탑)<br>- 강제 청산: 당일 15:20 | 일반적인 데이트레이딩 리스크 관리 |
| **최대 보유 기간** | 당일 청산을 원칙으로 함 (overnight 보유 금지) | 연구 노트의 "당일 또는 수일 내 청산" 중 당일 우선 |

### 단계 2: 백테스트 인프라 구축
1. **신호 생성 레이어 추가**:
   - `scripts/generate_fujimoto_signals.py`: ka10080 데이터를 읽어 위 규칙으로 신호 생성
   - 출력: `{date, stock_code, signal_type, entry_price, signal_time, score_details}`
2. **백테스트 엔진 연동**:
   - `scripts/backtest_fujimoto.py`: 신호를 입력으로 받아 포지션 시뮬레이션 (수수료/슬리피지 포함)
   - 지표: 총 수익, 승률, 수익 팩터, 최대 낙폭, 평균 보유 기간
3. **결과 검증 파이프라인**:
   - 최소 90거래일 데이터 필요 (현재 ~45일 → 다음 목표: 60일 달성 후 예비 백테스트)
   - 통과 기준: 
     - 승률 > 52%
     - 수익 팩터 > 1.3
     - 최대 낙폭 < 18%
     - 샘플 크기: 최소 50 거래

### 단계 3: 거시경제 요인 검토 (선택 사항)
사용자께서 이 전략에 거시 요인을 필수 요소로 보고 싶으시다면:
1. **데이터 소스 탐색**:
   - 글로벌 유동성: FRED의 `M2SL` (미국 M2 money stock) 또는 한국은행 유동성 지표
   - 미국 금리: FRED의 `DFF` (연방금리) 또는 미국 10년물 국채 수익률
   - 미국 증시: S&P 500 지수 또는 선물 (ES=F) 1분봉 (해외 브로커 API 필요)
   - 시장 심리: VIX 지수 또는 코스피 변동률
   - 국내 지표: 한은 기준금리, 소비자심리지수(CCSI), 수출입 증감률
2. **통합 방식** (예시):
   - 전략 점수에 가중치 부여: `final_score = base_score * (1 + macro_adjustment)`
   - 또는 레짐 필터: "미국 금리 하락기 + 글로벌 유동성 증가"일 때만 전략 신호 허용
3. **주의점**: 
   - 현재 연구 노트에는 이런 요인이 없으므로, **핵심 전략 순수성 유지**를 위해 
   - 별도 문서(`docs/strategies/fujimoto_shigeru_macro_filters.md`)에 보조 필터로 관리 권장

## 7. 결론 및 요구사항
**현재로써 가능한 최선의 길**: 
1. 연구 노트 기반 순수 기술/기본분석 전략을 먼저 백테스트 검증 (단계 1-2 완료)
