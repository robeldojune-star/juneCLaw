## 2. 1차로 추출한 핵심 요소

공개 자료에서 반복적으로 등장한 후지모토식 요소는 아래와 같다.

### 2.1 펀더멘털 기반 종목 선정

요약:

```text
단기 매매라도 아무 종목이나 보지 않고, 실적/재무가 양호한 기업을 먼저 선별한다.
```

후보 조건:

```text
- 매출 증가 또는 안정적 매출
- 영업이익 흑자
- 증익/증배 후보
- 과도한 부채 또는 관리/상폐 위험 제외
- PER/PBR/ROE 등 기본 밸류에이션 확인
```

우리 시스템 적용:

```text
Financial/Research AI가 OpenDART 기반 재무 필터를 담당한다.
후지모토식 종목 선정은 opening_multi_factor_v1의 사전 필터로 편입 가능하다.
```

---

### 2.2 기술적 타이밍: RSI와 단기 차트

공개 자료에서 다음 규칙이 언급된다.

```text
RSI 30 이하 매수 후보
RSI 70 이상 매도/익절 후보
1분/5분 차트로 진입·청산 타이밍 판단
거래량/거래대금으로 시장 관심도 확인
```

주의:

- RSI 30/70은 일반적으로 알려진 기준이며, 후지모토 개인의 정확한 실전 규칙으로 확정하지 않는다.
- 한국 주식 장초반 전략에 적용하려면 1분/5분 분봉 데이터 검증이 먼저 필요하다.

우리 시스템 적용:

```text
- 1차: RSI는 기존 technical_indicators 또는 분봉 RSI로 보조 점수화
- 2차: 장초반 10분/30분 오프닝 레인지와 함께 매수 타이밍 필터로 사용
```

### 2.3 거래량/거래대금 확인

후지모토식으로 요약되는 자료에서 거래량과 거래대금 확인이 강조된다.

우리 기존 전략축과 연결:

```text
S2. 수급 상관관계 / 거래량과 가격 변동 상관
```

편입 방식:

```text
- volume_spike_ratio
- price_volume_corr
- 거래대금 상위 필터
- 유동성 부족 종목 제외
```

### 2.4 자금관리: 1:2:6 분할 진입 후보

일부 공개 자료에서 `1:2:6` 자금 투입 규칙이 언급된다.

해석 후보:

```text
1단계: 소량 탐색 진입
2단계: 방향 확인 후 추가 진입
3단계: 추세 확정 후 본 진입
```

우리 시스템 적용 시 안전장치:

```text
- 실전 적용 전 모의투자에서만 테스트
- 각 단계는 별도 order_candidate로 기록
- 1:2:6은 총 투자금 배분 비율이지 무조건적인 물타기 규칙으로 쓰지 않는다.
- 최초 진입이 틀렸을 때 추가 매수 금지 조건을 둔다.
```

## 3. 전략 편입안

### 안 A. opening_multi_factor_v1의 보조 필터

가장 안전한 초기 방식.

```text
기존 3축 점수:
- 가격 변동성
- 수급 상관관계
- 90일 패턴

후지모토 보조 필터:
- 재무 건전성 통과
- RSI 과열/침체 확인
- 거래량/거래대금 충분
- 1:2:6 분할 진입 후보 생성
```

장점:

```text
- 기존 전략 구조를 흔들지 않음
- 후지모토 자료가 불완전해도 보수적으로 반영 가능
- 재무+기술+자금관리 역할이 명확함
```
