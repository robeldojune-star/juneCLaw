# 모바일 증권앱 스타일 차트 생성 가이드

## Trigger
사용자가 첨부한 증권앱 스크린샷처럼 "이 형식으로 차트"를 만들 수 있는지 묻거나, 차트 확인이 쉽도록 모바일 화면형 시각화를 요청할 때 사용한다.

## 목표 형식
- 세로형 모바일 비율: 대략 `1080 x 2400px` 또는 유사한 portrait 비율.
- 상단 앱 UI 모사:
  - 보라색 헤더: `종목차트 / 재무차트 / 지수차트`.
  - 종목 검색 박스: 별표, 종목명, 종목코드, `NXT거래가능` 같은 보조 텍스트.
  - 우측 현재가와 등락률을 크게 표시.
  - 탭/도구줄: `지표 / 일 / 1분 / 1틱`, `격자 / 확대 / 설정 / 도구`.
- 메인 차트:
  - 한국식 캔들 색상: 상승=빨강, 하락=파랑.
  - 이동평균: 5/10/20/60/120선.
  - 우측 가격축 별도 영역.
  - 현재가 파란 말풍선 라벨.
  - 최고가/최저가 주석: 빨강/파랑 화살표와 날짜 표시.
- 하단 패널:
  - 거래량 막대: 상승=빨강, 하락=파랑.
  - 거래량 이동평균 5/10/20/60/120선.
  - 우측 거래량 축은 K 단위 표기.
- 최하단 UI 모사:
  - 채팅 안내 바와 하단 메뉴 탭을 넣으면 사용자가 스크린샷 형식으로 인식하기 쉽다.

## 데이터 원칙
- 이 프로젝트에서는 가짜/샘플 가격 데이터를 쓰지 않는다.
- Supabase/Kiwoom `daily_prices` 실제 일봉을 읽어 생성한다.
- 사용자가 “2월 1일~오늘”처럼 날짜를 지정하면 휴장일은 실제 첫 거래일로 자연스럽게 보정한다.

## 구현 팁
- `matplotlib`로 정적 PNG를 만들면 모바일 스크린샷 형식 재현이 쉽다.
- 한글 폰트는 `Noto Sans CJK KR` 또는 `NanumGothic`을 우선 사용한다.
- 일부 유니코드 아이콘은 네모로 깨질 수 있으므로, 검증 후 `검색`, `격자`, `확대`, `설정`, `도구`, `三` 같은 한글/기본문자로 대체한다.
- 가격축과 현재가 라벨이 겹치면 현재가 주변 가격 tick을 숨긴다.
- Matplotlib volume 축에 `1e8` 같은 offset text가 보이면 `ax.yaxis.get_offset_text().set_visible(False)`로 숨긴다.

## 검증 체크리스트
1. 결과 이미지를 vision으로 열어 깨진 네모 글자 여부 확인.
2. 상단 UI, 종목명/현재가, 캔들/이평선, 우측 가격축, 최고/최저 주석, 거래량 패널이 모두 보이는지 확인.
3. 현재가 라벨과 가격 tick이 겹치지 않는지 확인.
4. 데이터 기간/row 수/최신 종가를 stdout 또는 리포트에 출력한다.
